```sh

```

The optional remote check sends HEAD requests to public links. Blocked or unsupported requests need a real-browser review because a service may reject automated clients or HEAD requests. Network failures are recorded for review. Route and asset failures always stop the local gate.

Playwright saves failure traces and screenshots under a separate `test-results/run-PID/` directory for each runner, with its HTML report under `playwright-report/run-PID/`. Concurrent local suites therefore keep their artifacts independent. `PORTFOLIO_TEST_ARTIFACTS` selects another private output directory. `npm audit` checks the locked JavaScript dependency tree separately.

After a build, `npm run test:deployment` checks the Docker/Compose package in an isolated container on a dynamically assigned localhost port. It exercises real nginx routing, redirects, 404 status, file permissions, video/audio byte ranges, WAV and caption MIME types and isolation of source/private files. Add `-- --browser` to run the browser suite against that nginx container too; the release package command requires this. Set `PORTFOLIO_DEPLOYMENT_REPORT` for a JSON evidence file. `PORTFOLIO_BROWSER_REPORT` selects the browser suite’s JSON evidence path.

Use `npm run build -- --outDir /private/build` for an isolated build, then set `PORTFOLIO_DIST_ROOT=/private/build` on the audit, static preview, browser runner or Docker smoke command. `PORTFOLIO_PREVIEW_PORT` selects a free preview port. Docker smoke copies the chosen build into a temporary context, avoiding a shared `dist/` rewrite. Release packaging requires the default `dist/` directory so its build and verification always refer to the same files.

For longer browser checks, run independent named segments and retain a separate report for each:

```sh
PORTFOLIO_DIST_ROOT=/private/build PORTFOLIO_PREVIEW_PORT=4392 \
  node scripts/verify-browser-segments.mjs /private/verification
```

Append names such as `workbench recovery` to run only those segments; `--list` shows the available groups. The runner owns one preview and forwards termination to its child process groups, then records interruption and removes the preview. It writes a durable `segments.json` after every segment plus each Playwright JSON report and log. A detached shell invocation can use `nohup` with stdin redirected from `/dev/null` and output redirected to a private log. An interrupted run remains incomplete; later passing subsets are separate evidence, rather than one completed suite report.

Public files belong in `public/`; raw captures, research, credentials and private verification evidence belong outside the repository. `scripts/audit-static.mjs` contains the curated media allowlist. When adding a capture, review the complete image or video for personal content, add its filename to the allowlist, provide descriptive text and captions, and record the capture provenance in `public/media/media-provenance.json`. Inspect video frames and the actual playback, including transitions and any hidden UI that opens during the flow.

Automated checks complement visual and editorial review. They cannot decide whether a recording is safe to publish, confirm a historical claim, or assess the quality of an image crop. Review those before marking the site ready to publish.
