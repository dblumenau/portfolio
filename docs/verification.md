Use `npm run build -- --outDir /private/build` for an isolated build, then set `PORTFOLIO_DIST_ROOT=/private/build` on the audit, static preview, browser runner or Docker smoke command. `PORTFOLIO_PREVIEW_PORT` selects a free preview port. Docker smoke copies the chosen build into a temporary context, avoiding a shared `dist/` rewrite. Release packaging requires the default `dist/` directory so its build and verification always refer to the same files.

For longer browser checks, run independent named segments and retain a separate report for each:


Append names such as `workbench recovery` to run only those segments; `--list` shows the available groups. The runner owns one preview and forwards termination to its child process groups, then records interruption and removes the preview. It writes a durable `segments.json` after every segment plus each Playwright JSON report and log. A detached shell invocation can use `nohup` with stdin redirected from `/dev/null` and output redirected to a private log. An interrupted run remains incomplete; later passing subsets are separate evidence, rather than one completed suite report.

When adding a capture, review the complete image or video for personal content, add its filename to the allowlist, provide descriptive text and captions, and record the capture provenance in `public/media/media-provenance.json`. Inspect video frames and the actual playback, including transitions and any hidden UI that opens during the flow.
